一个可以直接打开的静态航班地图，用于寻找苏联／俄罗斯设计飞机、L-410 与直升机的旅客航线。

正式站点：https://buaa.spotterblog.cn/sever-atlas/

冷门地方航线补查见 [冷门与线下航线](remote-routes.html) 与 [REMOTE-ROUTES-2026-11-04.md](REMOTE-ROUTES-2026-11-04.md)。

## 打开

双击 index.html 即可使用。HTML、CSS、JavaScript、Leaflet、底图和数据均在本地，不需要安装、构建、账户或地图 API key。推荐 Chrome、Edge、Safari 或 Firefox 的近期版本。

如需本地服务，在本目录运行：

    python3 -m http.server 8765

然后在浏览器打开 http://localhost:8765 。将整个目录上传到普通静态托管服务即可部署。只选择 index.html 上传不够。

## 阅读与行程规则

1. 官网计划时刻是证据边界：没有核实每次航班实际起降或当前余票，不能保证执行机型。
2. An-24 / An-26 / Q300 等混用记录保留替代机型提示。“仅看机型明确”只保留单一入选机型且证据明确的班次。官网合并标注TU 204/214的班次会被这个严格开关排除。
3. 直升机整条环线、链式航路和未公布抵达时间的记录，不编造中途到达时间。
4. 日期优先于星期；隔周首班日期不明的班次不进入日期推演；停飞与加班日期按来源处理。
5. 跨日 (+1) 来自来源明确偏移，或由已公布飞行时长、当地时间与 IANA 时区一致换算。无法一致换算时不计算连接。
6. 同机场间隔仅为时间差，不是最短转机时间或联程保护承诺；自行核实值机截止、换航站楼、行李和其他旅行条件。
7. 圆点为空心可能是参考位置；以悬停文字为准。坐标未核实的点保留在列表中，不任意落点。
8. 数据会随着真实时间自动隐藏已过期记录。更新需重新取得官网证据，不能只修改核查日期。

- THIRD_PARTY_NOTICES.md：第三方代码、地理数据与来源说明。
