# 北境航迹 · SEVER

一个可以直接打开的静态航班地图，用于寻找苏联／俄罗斯设计飞机、L-410 与直升机的旅客航线。

**核查日期：2026-11-04。这是研究快照，未达到“所有现存航司及全部当前航线”的完整覆盖。**

正式站点：https://buaa.spotterblog.cn/sever-atlas/

本次修正与个性化功能见 [GEO-CORRECTIONS-2026-11-04.md](GEO-CORRECTIONS-2026-11-04.md)；机型收录更新见 [UPDATE-2026-11-04.md](UPDATE-2026-11-04.md)。

## 打开

双击 index.html 即可使用。HTML、CSS、JavaScript、Leaflet、底图和数据均在本地，不需要安装、构建、账户或地图 API key。推荐 Chrome、Edge、Safari 或 Firefox 的近期版本。

如需本地服务，在本目录运行：

    python3 -m http.server 8765

然后在浏览器打开 http://localhost:8765 。将整个目录上传到普通静态托管服务即可部署。只选择 index.html 上传不够。

## 这版实际覆盖

- 17 家实际运营航司，2,002 条合并后的时刻记录。
- 290 个关联机场／起降点，286 个有可展示坐标；村镇参考点与查询器参考坐标明确区别于机场坐标。
- 默认隐藏 116 条散客购票资格尚未独立核实的高编号／包机标记班次。
- “一条时刻记录”不是一条航线或一次航班：同航班号的不同时间、机型和有效日期变体分别保留。
- 机型涵盖 An-2、An-24、An-26、An-28、An-38、Yak-40、Yak-42、Tu-204/214、Mi-8、L-410、SSJ100。
- 查询窗口并不统一：Rossiya 仅覆盖2026年11月4–10日（455次查询中42次连接失败）；IrAero 覆盖11月4日至12月4日；其余按各条官网有效期或指定日期。
- Red Wings 的 TU 204/214 已补入：官网合并标注，两种独立筛选均显示候选记录，未虚构逐班子型号。
- **Tu-134/154、Il-62/76、An-72/74 等尚无本次核实后录入的公开客运时刻。不能由此推断它们完全没有客运或包机机会。**

详细覆盖表和尚未解决的问题见 RESEARCH.md；完整结构化数据见 data/flights.json。

## 阅读与行程规则

1. 官网计划时刻是证据边界：没有核实每次航班实际起降或当前余票，不能保证执行机型。
2. An-24 / An-26 / Q300 等混用记录保留替代机型提示。“仅看机型明确”只保留单一入选机型且证据明确的班次。官网合并标注TU 204/214的班次会被这个严格开关排除。
3. 直升机整条环线、链式航路和未公布抵达时间的记录，不编造中途到达时间。
4. 日期优先于星期；隔周首班日期不明的班次不进入日期推演；停飞与加班日期按来源处理。
5. 跨日 (+1) 来自来源明确偏移，或由已公布飞行时长、当地时间与 IANA 时区一致换算。无法一致换算时不计算连接。
6. 同机场间隔仅为时间差，不是最短转机时间或联程保护承诺；自行核实值机截止、换航站楼、行李和其他旅行条件。
7. 圆点为空心可能是参考位置；以悬停文字为准。坐标未核实的点保留在列表中，不任意落点。
8. 数据会随着真实时间自动隐藏已过期记录。更新需重新取得官网证据，不能只修改核查日期。

## 文件

- index.html / style.css / app.js：静态应用。
- data/flights.js：直接打开网页使用的数据；flights.json：同内容的可编辑 JSON。
- data/coverage.json：航司核查清单；data/parse-issues.json：未展开的来源条目。
- data/verification.json：浏览器功能检查；data/data-validation.json：数据检查。
- data/source-manifest.json：原始快照文件哈希；sources/：证据材料。
- maintenance/：数据校验、发布、抓取脚本与查询模板；维护方法见其 README。
- THIRD_PARTY_NOTICES.md：第三方代码、地理数据与来源说明。

测试包含桌面、390px 手机、直接 file:// 离线打开、地图悬停、日期例外、行程增删排序和刷新保留、CSV 下载、全部306条名录。测试详情以 data/verification.json 为准。
